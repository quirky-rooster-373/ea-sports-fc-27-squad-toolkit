# EA Sports FC 27 Squad Toolkit — feature reference

Start with squad notes, organize tactic cards, and keep session records close at hand. These are the main areas covered by EA Sports FC 27 Squad Toolkit.

| Section | Description |
|---|---|
| Squad notes | Character or team groups presented with the context needed to organize a session. |
| Tactic cards | A dedicated section for tactic cards and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
